# ALACtoFLAC
Simple python script to transcode ALAC into level 8 FLAC losslessly.
Keeps all metadata, covers, vorbis comments, and more intact.

# Requirements:
``flac.exe`` & ``ffmpeg.exe``

# How:
1. Place script in any folder containing ALAC files
2. Ensure flac and ffmpeg are on PATH or with the script
3. Run and convert
